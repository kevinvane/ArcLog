# Nginx 访问 IP 来源分析 · 方案总结

本地分析 nginx 日志、用 2D 中国地图展示访问 IP 来源（省份 → 服务器固定位置）的飞线可视化项目。

## 1. 目标与约束

| 约束 | 决策 |
| --- | --- |
| 纯本地、隐私优先 | 纯前端，无后端、无外部网络请求 |
| 前端技术栈 | Vue 3 + TypeScript + Vite |
| 日志规模 | MB 级（单文件拖入浏览器解析即可） |
| IP 范围 | 以**国内**为主 |
| 飞线终点 | 固定的服务器位置（可配置） |

## 2. 技术选型与理由

- **可视化：ECharts + vue-echarts**
  - 原生支持 `geo` 地图 + `lines`（飞线特效）+ `effectScatter`（来源涟漪点），无需额外地图库。
- **IP 定位：ip2region xdb（自建解析器）**
  - 官方 `ip2region` npm 包依赖 Node `fs`，无法在浏览器运行。
  - 因此**自己实现纯 JS 的 xdb 读取器**：解析 256B 头 + 14B 段索引，对段索引做二分查找。完全离线、零依赖。
  - 数据库文件 `ip2region.xdb`（约 11MB）放在 `public/data/`，浏览器通过 `fetch` 加载为 `ArrayBuffer`。
- **地图底图：china-geojson**
  - 提取每个省份的 `cp`（中心点经纬度），作为飞线起点；无需额外坐标表。
- **聚合：前端内存计算**
  - 逐行解析日志 → 查 IP 归属省份 → 按省份计数，并对 IP→省份结果做缓存以加速。

## 3. 数据流

```
access.log
  └─ parseLog.ts      正则提取 IP / 状态码 / 路径
       └─ ip2region.ts  xdb 二分查找 → { country, province, city, isp }
            └─ geo.ts   省份全名 → 短名 → GeoJSON 中心点 [lng, lat]
                 └─ analyze.ts  按省份聚合计数 + 状态码 + Top 路径
                      └─ App.vue  ECharts geo + lines(飞线) + effectScatter(来源) + scatter(服务器)
```

## 4. 关键实现点

### 4.1 xdb 解析器（`src/utils/ip2region.ts`）
- v4 格式：`256B Header`（@8 为段索引起始指针，@12 为结束指针）→ 段索引每块 `14B = startIp(4) + endIp(4) + dataLen(2) + dataPtr(4)`。
- IP 在段索引中以**小端反序字节**存储，比较时按字节逆序比对（`cmpAt`）。
- 命中后按 `dataPtr` 读取 `dataLen` 字节 UTF-8 字符串，格式：`国家|省份|城市|ISP|代码`。
- 已对真实 IP（如 `114.114.114.114 → 江苏省`）验证正确。

### 4.2 省份映射（`src/utils/geo.ts`）
- `PROVINCE_ALIAS`：ip2region 返回的省份全名（如 `广东省`）→ GeoJSON 短名（`广东`）。
- `centerMap`：从 `china.json` 提取各省份中心点坐标。
- `resolveServerLocation`：支持 `省份名` 或 `lng,lat` 两种输入，默认北京。

### 4.3 飞线渲染（`src/App.vue`）
- `geo` 组件加载注册好的 `china` 地图，支持 `roam` 缩放拖拽。
- `lines` 系列：每条 `coords: [省份中心, 服务器坐标]`，带 `effect` 箭头流动动画。
- `effectScatter`：来源省份点，大小按访问量 `sqrt` 缩放。
- `scatter(pin)`：服务器位置标记。

## 5. 目录结构

```
nginx-ip-map/
├─ index.html
├─ vite.config.ts
├─ package.json
├─ public/data/ip2region.xdb      # IP 数据库（11MB）
└─ src/
   ├─ main.ts                     # 注册 ECharts 组件 + 注册中国地图
   ├─ App.vue                     # 主界面：拖拽日志 + 配置 + 地图 + 统计
   ├─ style.css
   ├─ assets/china.json           # 中国省级 GeoJSON
   └─ utils/
      ├─ ip2region.ts             # 纯 JS xdb 解析器
      ├─ parseLog.ts              # nginx 日志解析
      ├─ geo.ts                   # 省份别名 / 中心点 / 服务器坐标
      └─ analyze.ts               # 聚合统计
```

## 6. 运行方式

```bash
npm install      # 安装依赖
npm run dev      # 开发模式，浏览器打开 http://127.0.0.1:5173/
npm run build    # 生产构建，产物在 dist/
```

使用：
1. 拖入 `access.log`（支持 combined 格式），或点「生成示例数据」预览效果。
2. 左侧填写服务器位置（如 `北京` 或 `120.15,30.28`）。
3. 地图显示各省 → 服务器的金色飞线 + 橙色来源点 + 绿色服务器标记，侧栏含省份 Top、状态码等统计。

> 注意：Vite dev 已配置 `host: '0.0.0.0'` + `strictPort: true`。浏览器请用 `http://127.0.0.1:5173/`，避免 `localhost` 的 IPv6 解析问题。

## 7. 已验证 / 限制

- ✅ TypeScript 类型检查 + 生产构建通过。
- ✅ xdb 解析器对真实 IP 返回正确省份。
- ✅ 构建产物包含 `ip2region.xdb` 资源。
- ⚠️ 飞线地图的浏览器实际渲染需本地 `npm run dev` 自测。
- ⚠️ 仅国内省份有坐标；海外/未知归属 IP 计为「海外」统计项，不绘飞线。
- ⚠️ MB 级日志在浏览器内解析可行；GB 级需改为 Web Worker 或加轻后端。
