# 自定义日志格式 · 设计文档

> 状态：已实现 | 关联技术债：优化路线图「日志格式仅适配 combined」

## 1. 背景与目标

当前解析器硬编码 combined 格式。使用自定义 `log_format` 的 nginx（如加了
`$http_x_real_ip`、CDN 回源字段、或调整过字段顺序）会解析失败或字段错位。

目标：用户粘贴自己的 `log_format` 配置，程序**自动编译为正则**并完成校验，
无需用户理解正则。

## 2. 核心设计：log_format → 正则编译器

### 2.1 输入预处理
- 剥离 `log_format <name>` 前缀与结尾 `;`
- 拼接多行字符串（nginx 的 format 常折行书写）
- 兼容直接粘贴格式串本身（不含变量名前缀）

### 2.2 变量 → 命名捕获组映射

| nginx 变量 | 捕获组 | 正则片段 |
| --- | --- | --- |
| `$remote_addr` / `$http_x_forwarded_for`* | `ip` | `\S+` |
| `$time_local` | `time` | `[^\]]+` |
| `$time_iso8601` | `time` | `\S+` |
| `$request` | `request` | `[^"]*` |
| `$request_method` | `method` | `\S+` |
| `$uri` / `$request_uri` / `$document_uri` | `path` | `\S+` |
| `$status` | `status` | `\d{3}` |
| `$body_bytes_sent` / `$bytes_sent` | `bytes` | `\S+` |
| `$http_user_agent` | `ua` | `[^"]*` |
| `$http_referer` | `referer` | `[^"]*` |
| 其他未知变量 | 占位 | `\S+` |

\* 当格式中同时存在 `$remote_addr` 与 `$http_x_forwarded_for` 时，优先取后者作为客户端 IP（反代场景更准确），规则见 2.4。

### 2.3 编译算法

```
tokenize(format):
  按 $xxx 切分 → [literal, var, literal, var, ...]
buildRegex(tokens):
  literal → re.escape(literal)          # 字面量正则转义
  var     → VAR_PATTERNS[name] ?? '(?<x_N>\\S+)'
  拼接 '^' + parts + '$'
```

### 2.4 字段归一化

编译产物统一归一为内部 `LogLine` 结构：

- 有 `ip` 组即用之；若同时捕获到 `x_forwarded_for` 且非 `-`，覆盖为客户端 IP
- 有 `request` 组时拆分 `METHOD URI PROTO`（容错两段式）
- 有独立 `method`/`path` 组时直接使用
- `time_local` / `time_iso8601` 分别走对应时间解析，产出 `ts`
- `status` 缺失时不影响 IP 定位主流程

## 3. 校验闭环（防错配）

应用格式前，用当前日志文件的前 **1000 行** 试匹配：

| 匹配率 | 行为 |
| --- | --- |
| ≥95% | ✅ 绿色提示，允许应用 |
| 50%~95% | ⚠️ 黄色警告，展示首条失败行样例，仍可强制应用 |
| <50% | ❌ 红色错误，禁止应用 |

同时展示首行解析预览（ip / status / path / time 各字段值），让用户直观确认字段没有错位。

## 4. 存储与应用

- 自定义格式串存 `localStorage['arclog-logformat']`
- 「恢复默认」清除该键，回退内置 combined 快速路径
- 解析层改造：
  - 新增 `createParser(customFormat?): Parser`
    - 无自定义 → 现有 combined 快速路径（性能不变）
    - 有自定义 → 动态正则路径
  - Worker 的 `analyze` 消息携带 `format` 字段，Worker 内构建解析器

## 5. UI 设计（侧栏 ⚙ 设置面板）

```
┌─ ⚙ 日志格式 ────────────────────────────┐
│ ┌─────────────────────────────────────┐ │
│ │ log_format main '$remote_addr - ...' │ │
│ └─────────────────────────────────────┘ │
│ ✓ 匹配率 99.2%（992/1000 行）            │
│ 预览: ip=1.2.3.4 status=404 path=/admin │
│ [ 应用 ]        [ 恢复默认 ]             │
└─────────────────────────────────────────┘
```

- 未加载日志时也可保存格式（校验在下次分析时执行）
- 面板入口放侧栏「服务器位置」旁的齿轮按钮

## 6. 边界与限制

- 仅支持空格分隔的文本格式；JSON 日志不在范围内（可作后续扩展）
- 引号内嵌套引号的畸形 format 不支持，编译失败时报"无法识别的格式"
- 极端正则回溯风险低：所有片段均为线性匹配，无嵌套量词
